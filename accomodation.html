Staying at Tewinbury

If you would like to stay with us at Tewinbury, we have a discount code available for all wedding guests.


Follow this link to book a room - it should take you directly to the booking page with the discount code applied. Alternatively, head to www.tewinbury.co.uk/stay, click book, then select the correct dates and add the promo code 'MAR25FC' to see the discounted rates. If you require an accessible room, please email Tewinbury directly before booking at reservations@tewinbury.co.uk.


Please note the following before you book:


  • Breakfast is included in all bookings.
  • The discount code is only available for the five days over the wedding (between 6th and 11th of March). If you would like to stay outside those dates, you need to make a separate booking for the same room type and just add a note in the booking notes to say you have another room. Tewinbury will match the rooms up so you won't need to switch over.
  • The discount code is only available until 8 weeks before the wedding (11/01/2025).
  • Check-in time is from 3pm, and check-out is before 11am. There will be time during the wedding day for people to check-in to their rooms.
